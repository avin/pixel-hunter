# Пиксельный охотник

Помощник для игр, который следит за цветом выбранных пикселей на экране и при его изменении нажимает нужную кнопку. 
Например, использует зелье лечения, когда здоровье падает.

Может пригодиться в играх вроде Path of Exile, Diablo или Terraria, где в разгар боя легко забыть о лечении.
