GeForce RTX 3070, основной монитор 3440 × 1440.

## Оставшиеся ручные проверки

Пункты 3.5 и 7.2 в change пока открыты. Windows Computer Use не получает
снимки ни Pixel Hunter, ни тестового окна: `window capture timed out` /
`FrameArrived timed out`. Повтор с обновлённым окном и перезапуском JS helper
не помог; пользователь подтвердил, что рабочий стол разблокирован.
Ручной просмотр overlay и установленного release не объявлены выполненными.

Для проверки тестового окна запустите из корня:

```powershell
./scripts/run-icon-fixture.ps1 -Launch
```

1. Установите итоговый NSIS release. Запустите приложение; оно требует
   стандартного подтверждения UAC. Уберите пользовательский OpenCV из PATH.
2. Создайте отдельный тестовый профиль для `icon-search-fixture.exe`,
   отслеживание с нажатием `Q` и cooldown 500 мс.
3. Добавьте пиксель в красном квадрате. В захвате иконки выделите синюю
   область поиска, затем цветной квадрат внутри неё. Проверьте подписи
   возле курсора, переключение этапа, drag в обратном направлении и
   видимость подсказки у края экрана. Подсказка не должна перехватывать drag.
4. Запустите отслеживание и переключитесь в тестовое окно. Счётчик Q должен
   увеличиваться при перемещениях иконки внутри области. Нажмите Toggle icon:
   при условии присутствия счётчик должен остановиться. Измените условие на
   отсутствие, вернитесь в окно: счётчик должен снова увеличиваться.
5. Добавьте ещё одну иконку и отмените Esc отдельно на этапе области поиска
   и на этапе образца: новый элемент и оставшиеся PNG не должны появиться.
6. Откройте снимок по миниатюре: обе рамки должны совпадать с выбранными
   областями. Закройте кликом и клавишей; повторное открытие переиспользует
   окно. Перезапустите приложение и проверьте сохранённое условие.
7. Удалите тестовую иконку и профиль: все три файла иконки должны исчезнуть.

Результат этого сценария требуется записать перед закрытием двух пунктов.
