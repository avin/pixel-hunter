# Proposal

## Why

Отслеживание срабатывает по цвету пикселей на экране игры, поэтому пользователю нужен способ указать точку прямо на кадре игры и задать условие для её цвета. Overlay поверх полноэкранной игры ненадёжен, поэтому выбор точки идёт по снимку экрана: приложение ждёт возврата пользователя в игру, делает снимок и показывает его в собственном полноэкранном окне.

Изменение опирается на `add-app-foundation` (профили, отслеживания, хранилище).

## What Changes

- Интерактивное добавление пикселя:
  - до 10 с ждём, пока активным станет окно процесса профиля, затем ещё 3 с;
  - делаем снимок основного монитора через DXGI Desktop Duplication и проигрываем звук затвора;
  - сворачиваем игру и показываем полноэкранный выбор точки с курсором-крестиком;
  - клик добавляет пиксель в отслеживание.
- Таблица пикселей отслеживания: миниатюра снимка с отметкой, цвет, условие «равно / не равно», допуск в процентах; удаление пикселя.
- Полноэкранный просмотр снимка с отметкой выбранного пикселя, закрывается любым кликом или клавишей.
- Снимки хранятся рядом с конфигурацией и удаляются вместе с пикселем, отслеживанием или профилем.
- Общий Rust-модуль захвата основного монитора через DXGI, который переиспользует `add-tracking-engine`.

## Capabilities

### New Capabilities

- `pixel-capture`: сценарий интерактивного выбора точки по снимку экрана игры.
- `tracked-pixels`: список пикселей отслеживания, их условия, допуск, снимки и просмотр.

### Modified Capabilities

Нет. Каскадное удаление снимков при удалении отслеживания или профиля описано в `tracked-pixels` как новое поведение и не меняет требований `profile-management` и `tracker-management`.

## Impact

- `src-tauri`:
  - фичи крейта `windows` для Direct3D 11, DXGI, GDI и `Win32_Media_Audio`;
  - крейт `image` с PNG;
  - фича `protocol-asset` у `tauri`;
  - модули захвата экрана, сценария захвата, звука;
  - второе окно Tauri для выбора точки и просмотра снимка.
- `tauri.conf.json`: asset protocol со scope на каталог снимков; capability для второго окна.
- `src`: точка входа второго окна, таблица пикселей на `TrackerPage`, endpoints для пикселей и события статуса захвата.
- Модель `Tracker` получает поле `pixels` со значением по умолчанию, поэтому существующие конфигурации читаются без миграции.
