## MODIFIED Requirements

### Requirement: Таблица пикселей отслеживания
Экран отслеживания варианта «Пиксели» SHALL показывать таблицу пикселей с колонками: миниатюра снимка, цвет, условие, допуск. Редактор SHALL содержать раздельные кнопки «Добавить пиксель» и «Добавить иконку». Если нет ни пикселей, ни иконок, SHALL показываться общее пустое состояние с предложением добавить любой из них. Если есть только иконки, SHALL показываться их список без общего пустого состояния. В варианте «Хоткей» эта таблица SHALL NOT показываться.

#### Scenario: Отслеживание с пикселями
- **WHEN** пользователь открывает отслеживание варианта «Пиксели» с двумя пикселями
- **THEN** таблица содержит две строки с миниатюрой, цветом, условием и допуском каждого

#### Scenario: Пустое отслеживание
- **WHEN** у отслеживания варианта «Пиксели» нет пикселей и иконок
- **THEN** таблица показывает пустое состояние и раздельные кнопки добавления пикселя и иконки

#### Scenario: Вариант «Хоткей»
- **WHEN** пользователь открывает отслеживание варианта «Хоткей», у которого сохранены пиксели
- **THEN** таблицы пикселей на экране нет
#### Scenario: Совместное редактирование
- **WHEN** у отслеживания сохранены пиксель и иконка
- **THEN** редактор показывает оба элемента со своими параметрами и обе кнопки добавления

#### Scenario: Только иконки
- **WHEN** у отслеживания нет пикселей, но есть иконки
- **THEN** иконки доступны для редактирования, а общее пустое состояние отсутствует
