# Proposal

## Why

Пиксели проверяются по фиксированным координатам, поэтому не подходят для иконок эффектов, которые появляются в разных местах панели игры. Поиск образца внутри выбранной области позволит, например, нажать навык снятия проклятия при появлении его иконки и совместить эту проверку с цветом пикселя.

## What Changes

- Расширить существующий вариант условия «Пиксели» иконками, без нового варианта триггера: разрешить только пиксели, только иконки или их совместную проверку через AND.
- Добавить две раздельные кнопки «Добавить пиксель» и «Добавить иконку».
- После снимка при добавлении иконки сначала нарисовать прямоугольник поиска, затем выделить прямоугольник образца внутри него на том же снимке.
- Для каждой иконки сохранять признак «Иконка должна быть» / «Иконки не должно быть» и регулируемый порог сходства.
- Искать образец в любой позиции выбранной области с помощью OpenCV на стороне Rust; использовать один кадр для всех визуальных проверок одного опроса.
- Показывать миниатюру и полноэкранный просмотр исходного снимка с областью поиска и выделением образца.
- В обоих редакторах показывать справа снизу от курсора серую подсказку с чёрным текстом текущего шага: «выбрать пиксель», «выбрать область для поиска иконки», «выбрать область иконки».
- Сохранять и удалять файлы иконок вместе с их условиями, отслеживаниями и профилями; читать прежние настройки без миграции вручную.

## Capabilities

### New Capabilities

- `icon-search`: выбор области и образца, настройка присутствия/отсутствия, поиск перемещающейся иконки, хранение и просмотр снимков.

### Modified Capabilities

- `pixel-capture`: подсказка текущего действия возле курсора и взаимное исключение захватов пикселей и иконок.
- `tracked-pixels`: общий редактор с независимыми кнопками добавления и корректным пустым состоянием при наличии только иконок.
- `tracking-engine`: совместная проверка пикселей и иконок, изменения на лету и пауза для обоих видов захвата.
- `tracker-run-control`: готовность условия при наличии хотя бы одного пикселя или иконки.

## Impact

Rust: `config.rs`, `profiles.rs`, `commands.rs`, `lib.rs`, `screen.rs`, `engine/machine.rs`, `engine/poller.rs`, `pixel_capture.rs`, `screen_overlay.rs`, `screenshots.rs`, `screenshot_viewer.rs` и новый модуль сопоставления образцов. Frontend: типы/API/store захвата, `PixelsSection`, picker/viewer, миниатюры и сообщения готовности. Добавляется зависимость Rust OpenCV и воспроизводимая сборка/поставка её native runtime для Windows. Существующие пиксели, хоткеи и действия сохраняют свою семантику. Масштабирование/поворот образцов и поиск на дополнительных мониторах вне объёма изменения.
