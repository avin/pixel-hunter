# Proposal

## Why

Срабатывание отслеживания сейчас не имеет настраиваемого звукового сопровождения. Пользователю нужен узнаваемый сигнал для каждого действия с возможностью заранее послушать его и подобрать громкость.

## What Changes

- В строке выбора типа действия добавить справа группу «Звук», select и компактный слайдер громкости, оставив свободное пространство между типом и звуком. В раскрытом меню каждого звука справа от его названия разместить кнопку воспроизведения.
- Предложить «Без звука» первым пунктом и 20 самостоятельно синтезированных коротких звуков с английскими названиями.
- Кнопкой в пункте меню прослушивать звук этого пункта без изменения выбора и закрытия меню; после отпускания слайдера громкости или клавиши его управления прослушивать выбранный звук с окончательным уровнем.
- Сохранять звук и громкость для действия каждого отслеживания, без потери при редактировании шагов.
- Воспроизводить сигнал один раз при фактическом начале действия в движке, после задержки и ожидания очереди.
- Для новых и ранее сохранённых действий использовать «Без звука» и громкость 50%.

## Capabilities

### New Capabilities

- Нет.

### Modified Capabilities

- `tracker-actions`: каталог звуков, выбор, предпрослушивание, громкость, сохранение и совместимость старых настроек.
- `tracking-engine`: звуковой сигнал при начале действия, отсутствие сигнала у отменённых срабатываний и независимость от состояния интерфейса.

## Impact

- Frontend: `ActionSection`, общие типы `Action`, API Tauri, редакторы действий и тестовый backend.
- Backend: модель `Action`, валидация и сохранение настроек, команды предпрослушивания и каталога, место исполнения действия в `engine.rs` и новый модуль звука.
- Настройки расширяются обратно совместимыми полями; старые профили продолжают открываться.
- Генерация и воспроизведение локальны, без сети и сторонних аудиозаписей. Реализация опирается на Windows audio API из существующей зависимости `windows`; звук затвора захвата пикселя сохраняет своё поведение.
