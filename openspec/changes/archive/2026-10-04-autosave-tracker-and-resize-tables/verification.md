# Проверка реализации

- `npm test`: 136 тестов проходят, 13 файлов.
- `npm run build`: TypeScript и сборка Vite проходят.
- `git diff --check`: ошибок форматирования нет.
- Поведенческие тесты покрывают debounce 500 мс, запись последней версии, отказ записи некорректного черновика, сохранность ввода при задержанном успехе/ошибке, повтор после исправления/выхода, завершение записи перед навигацией и отмену таймера при размонтировании.
- Проверки разделителя покрывают перетаскивание, границы, клавиатуру, ARIA, процентное сохранение, повреждённое/недоступное хранилище и изменение размера без утраты предпочтения.
- В браузере на временном стенде с существующим fake backend вручную проверены большие и пустые таблицы, захват пикселя, ошибки при вводе, размеры 900 × 600 и 1200 × 900, независимая прокрутка, разделитель команд, автосохранение без выхода, повторная загрузка редактора и восстановление процентной пропорции. В маленьком окне отображаемая доля ограничивается до 50%, а при увеличении возвращается выбранная доля около 24.625%.
- Дополнительно проверено визуальное увеличение стенда до 150%; это не проверка системного масштаба Windows.

## Незавершённые проверки

- Задача 3.4 остаётся открытой: нативный Pixel Hunter при системном масштабе Windows 150% не проверен.
- Задача 5.2 остаётся открытой: сквозной сценарий пройден на браузерном стенде, но перезапуск нативного приложения и запись реальным Tauri backend не проверены в этой сессии.
- Нативное окно найдено через `computer-use`, но обе попытки снимка завершились таймаутом захвата. Дерево доступности без снимка содержит только оболочку WebView без полей и команд; оно не позволяет безопасно выполнить и подтвердить сценарий.
- Формат профилей и Rust API не менялись. Временный стенд не использовал конфигурацию пользователя.

Существующие предупреждения сборки: `__dirname` в конфигурации Vite и JS chunk больше 500 kB.
