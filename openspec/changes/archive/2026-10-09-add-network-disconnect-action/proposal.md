# Proposal

## Why

Отслеживание умеет только нажимать клавиши. Для игр, которые нужно сбрасывать с сервера, а не нажимать кнопку в клиенте, требуется действие, которое обрывает TCP-соединения процесса профиля так же, как это уже работает в PoeLifer: через `SetTcpEntry` со состоянием `DELETE_TCB`.

## What Changes

- В select типа действия появляется «Разрыв сетевого соединения». У типа нет своих полей: цель — процесс профиля.
- При срабатывании приложение находит все процессы с именем исполняемого файла профиля и для их IPv4 TCP-соединений в состояниях established, SYN sent и SYN received вызывает `SetTcpEntry` с `DELETE_TCB`. UDP, IPv6 и остальные состояния TCP не затрагиваются.
- Действие этого типа считается настроенным само по себе: отслеживание с пикселями можно запустить без шагов нажатий.
- Смена типа с непустой последовательности клавиш запрашивает подтверждение, потому что шаги при этом заменяются. Звук действия сохраняется, как и сейчас.
- Существующие профили с типом «Нажатие клавиш» читаются без миграции.

## Capabilities

### New Capabilities

- `network-disconnect-action`: настройка и выполнение разрыва TCP-соединений процесса профиля.

### Modified Capabilities

- `tracker-actions`: в выборе типа есть «Разрыв сетевого соединения», у него нет формы настроек, а уход с настроенного «Нажатия клавиш» требует подтверждения.
- `tracker-run-control`: отслеживание с разрывом сети и пикселями можно запустить; отсутствие шагов блокирует запуск только у «Нажатия клавиш».

## Impact

- `src-tauri`: вариант `ActionKind::NetworkDisconnect`, снимок имени процесса в задании движка, обход таблицы TCP и `SetTcpEntry`. Фича `windows`: `Win32_NetworkManagement_IpHelper`. Отдельного запроса прав нет: release-сборка уже поднимается до администратора, без чего `SetTcpEntry` не срабатывает.
- `src`: запись в реестре типов действий, краткое пояснение вместо редактора, подтверждение смены типа, проверка полноты отслеживания по типу действия.
- Глобальная горячая клавиша дисконнекта из PoeLifer в это изменение не входит.
