# Spec Delta

## ADDED Requirements

### Requirement: Тип «Разрыв сетевого соединения»
Select типа действия SHALL содержать вариант «Разрыв сетевого соединения». При его выборе форма SHALL не содержать полей ввода и SHALL пояснять, что срабатывание обрывает TCP-соединения процесса профиля.

#### Scenario: Пункт в списке
- **WHEN** пользователь открывает select типа действия
- **THEN** в нём есть «Нажатие клавиш» и «Разрыв сетевого соединения»

#### Scenario: Форма без полей
- **WHEN** выбран «Разрыв сетевого соединения»
- **THEN** под select нет полей ввода, а пояснение говорит об обрыве TCP-соединений процесса профиля

### Requirement: Подтверждение смены типа
Смена типа SHALL запрашивать подтверждение, если у текущего действия есть настройки, которые будут потеряны. Для «Нажатия клавиш» такая настройка — непустой список шагов. У «Разрыва сетевого соединения» своих настроек нет, поэтому уход с него подтверждения SHALL NOT требовать. Подтверждённая смена SHALL подставлять настройки нового типа и SHALL сохранять звук. Отказ SHALL оставлять прежний тип и его настройки.

#### Scenario: Уход с записанной последовательности
- **WHEN** у «Нажатия клавиш» есть шаги, выбран Arcade Coin, и пользователь подтверждает переход на «Разрыв сетевого соединения»
- **THEN** тип становится «Разрыв сетевого соединения», шаги пропадают, звук остаётся Arcade Coin

#### Scenario: Отказ
- **WHEN** пользователь выбирает другой тип и отказывается от подтверждения
- **THEN** тип и шаги остаются прежними

#### Scenario: Пустая последовательность
- **WHEN** у «Нажатия клавиш» нет шагов и пользователь выбирает «Разрыв сетевого соединения»
- **THEN** тип меняется сразу, без запроса подтверждения

#### Scenario: Возврат к нажатиям
- **WHEN** выбран «Разрыв сетевого соединения» и пользователь выбирает «Нажатие клавиш»
- **THEN** тип меняется сразу на «Нажатие клавиш» с пустым списком шагов, а звук сохраняется
