# Проверка redesign-desktop-interface

Дата: 2026-10-04.

## Автоматические результаты

- `npm test`: 12 файлов, 99 тестов проходят.
- `npm run build`: TypeScript и production-сборка проходят.
- `git -c core.whitespace=cr-at-eol diff --check`: проходит (репозиторий хранит CRLF).
- Проверены локальный ввод/blur/Enter без записи, отсутствие лишнего запроса,
  нулевая пауза, валидация и фокус, история, смена отслеживания и профиля,
  ошибка записи/повтор, один запрос и первоначальный адрес при задержанном ответе.
- Проверены независимые обновления пикселя, действия и запуска с сохранением
  черновика, раскрытие дерева без активации, удаление через guard и отмена.
- Существующие проверки захвата, отмены, физической точки и DPR проходят.

## Не выполнено в реальном Tauri

В этой сессии управление нативными окнами недоступно. Задачи 3.2 (ручной
просмотр), 5.2 и 5.3 остаются открытыми; визуальный результат и восстановление
после настоящего перезапуска приложения не подтверждены.

Для завершения:

1. Запустить `npm run tauri dev`. Проверить все страницы, диалоги, загрузку,
   ошибки и пустые состояния при 1100 × 750 и 900 × 600.
2. Повторить при Windows 100% и 150%, длинных именах и больших таблицах:
   команды и статус видимы, таблицы прокручиваются внутри панелей, оболочка
   не имеет горизонтальной прокрутки; проверить клавиатуру и видимый фокус.
3. Проверить физическое соответствие полноэкранного выбора/просмотра снимка.
4. Изменить имя/задержки, затем пиксель и действие; сделать черновик невалидным,
   попытаться сменить профиль, проверить оставшийся ввод и исходный профиль.
   Исправить, перейти, вернуться, затем перезапустить приложение и проверить
   сохранённые настройки и активность движка.
5. После фактического выполнения записать результаты и закрыть оставшиеся задачи.
