# Spec Delta

## MODIFIED Requirements

### Requirement: Список профилей на стартовом экране
При запуске без восстанавливаемого экрана профиля приложение SHALL показывать список сохранённых профилей с именем и именем процесса каждого. Если профилей нет, SHALL показываться пустое состояние с предложением создать профиль.

#### Scenario: Есть сохранённые профили
- **WHEN** пользователь запускает приложение, в хранилище есть профили, и нет сохранённого экрана профиля
- **THEN** стартовый экран показывает каждый профиль с его именем и именем процесса

#### Scenario: Профилей нет
- **WHEN** пользователь запускает приложение впервые
- **THEN** стартовый экран показывает пустое состояние и кнопку создания профиля

## ADDED Requirements

### Requirement: Восстановление последнего экрана
Приложение SHALL запоминать открытый экран и при следующем запуске открывать его снова. Экран профиля или его отслеживания SHALL делать этот профиль активным, и отслеживания с сохранённым состоянием «запущено» SHALL работать.

#### Scenario: Перезапуск внутри профиля
- **WHEN** пользователь включил отслеживания и закрыл приложение на обзоре этого профиля
- **THEN** приложение открывает обзор того же профиля, и те же отслеживания работают

#### Scenario: Перезапуск в редакторе
- **WHEN** пользователь закрыл приложение в редакторе отслеживания профиля
- **THEN** открывается этот редактор, профиль активен, и ранее запущенные отслеживания работают

#### Scenario: Перезапуск со списка
- **WHEN** пользователь вернулся к списку профилей и закрыл приложение
- **THEN** открывается список профилей, и ни одно отслеживание не работает
- **AND** флаги «запущено» остаются сохранёнными

#### Scenario: Профиль удалён
- **WHEN** сохранённый экран ссылается на профиль, которого больше нет
- **THEN** открывается список профилей

#### Scenario: Отслеживание редактора удалено
- **WHEN** сохранённый экран ссылается на удалённое отслеживание существующего профиля
- **THEN** открывается обзор этого профиля
