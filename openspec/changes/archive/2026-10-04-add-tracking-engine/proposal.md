# Proposal

## Why

После трёх предыдущих изменений у отслеживания есть пиксели с условиями и действие, но ничто их не исполняет. Нужен движок, который:
- в открытом профиле опрашивает пиксели запущенных отслеживаний;
- работает только когда активно окно игры;
- выполняет действия по очереди с заданными задержками и паузами.

Изменение завершает серию: опирается на `add-app-foundation`, `add-pixel-capture` (модуль `screen`, `foreground`, пиксели) и `add-key-sequence-action` (исполнитель последовательности).

## What Changes

- Кнопка старта и остановки у каждого отслеживания в списке профиля. Состояние «запущено» сохраняется.
- Вход в профиль автоматически запускает отслеживания с сохранённым флагом, выход из профиля останавливает все. Активен только открытый профиль.
- Движок в Rust:
  - опрос раз в 50 мс, только пока активное окно принадлежит процессу профиля;
  - проверка пикселей по допуску поканально в RGB, срабатывание, когда все пиксели прошли условие;
  - задержка перед действием, общая очередь действий по одному, пауза до возобновления опроса;
  - без перепроверки условия перед действием.
- Движок приостанавливается на время захвата пикселя.
- Экран профиля показывает, активно ли сейчас окно игры.

## Capabilities

### New Capabilities

- `tracker-run-control`: запуск и остановка отслеживаний, сохранение состояния, жизненный цикл при входе в профиль и выходе из него.
- `tracking-engine`: опрос пикселей, сравнение цветов, срабатывание и очередь выполнения действий.

### Modified Capabilities

Нет.

## Impact

- `src-tauri`:
  - поток движка и его управляющий канал;
  - поток исполнителя действий;
  - команды `engine_activate`, `engine_deactivate`, `tracker_set_running`;
  - уведомление движка из `ConfigStore` о мутациях;
  - флаг паузы от сценария захвата;
  - поле `Tracker.isRunning` с `#[serde(default)]`.
- `src`: общий элемент маршрута профиля, который активирует и деактивирует движок; кнопка старта и остановки в списке отслеживаний; индикатор активности окна игры по событию `engine://status`.
