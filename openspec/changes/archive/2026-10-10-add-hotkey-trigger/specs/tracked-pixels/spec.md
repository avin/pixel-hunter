# Spec Delta

## MODIFIED Requirements

### Requirement: Таблица пикселей отслеживания
Экран отслеживания варианта «Пиксели» SHALL показывать таблицу пикселей с колонками: миниатюра снимка, цвет, условие, допуск. Если пикселей нет, SHALL показываться пустое состояние с предложением добавить пиксель. В варианте «Хоткей» эта таблица SHALL NOT показываться.

#### Scenario: Отслеживание с пикселями
- **WHEN** пользователь открывает отслеживание варианта «Пиксели» с двумя пикселями
- **THEN** таблица содержит две строки с миниатюрой, цветом, условием и допуском каждого

#### Scenario: Пустое отслеживание
- **WHEN** у отслеживания варианта «Пиксели» нет пикселей
- **THEN** таблица показывает пустое состояние и кнопку добавления пикселя

#### Scenario: Вариант «Хоткей»
- **WHEN** пользователь открывает отслеживание варианта «Хоткей», у которого сохранены пиксели
- **THEN** таблицы пикселей на экране нет
