# Proposal

## Why

Сейчас действие «Нажатие клавиш» удерживает каждую клавишу только 40–90 мс, и этот диапазон зашит в исполнитель. Для зарядки энергии и других действий в игре нужно задавать более длительное удержание отдельно для каждого нажатия.

## What Changes

- В каждой строке таблицы нажатий появится диапазон «Удержание, мс», в том числе у первого шага.
- Длительность удержания основной клавиши будет случайно выбираться из диапазона этого шага при каждом выполнении. Модификаторы остаются нажатыми до её отпускания.
- Новые шаги и ранее сохранённые шаги без этого параметра получают диапазон 40–90 мс — текущий хардкод.
- Диапазон сохраняется вместе со шагом; перезапись сочетания и удаление соседних шагов сохраняют его.
- Задержка перед шагом и технические интервалы между событиями модификаторов сохраняют текущее поведение.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `key-sequence-action`: индивидуальный настраиваемый диапазон удержания для каждого шага, его сохранение, проверка и применение при эмуляции ввода.

## Impact

- Backend: `src-tauri/src/action.rs` (модель, serde-default, валидация), `src-tauri/src/key_sequence.rs` (исполнение), связанные фикстуры и тесты конфигурации/действий.
- Frontend: `src/store/types.ts`, `KeySequenceEditor` и `StepRow`, существующий редактор диапазонов и `src/test/fakeBackend.ts`.
- JSON каждого `KeyStep` расширяется полем `holdMs: { min, max }`; старые конфигурации читаются без ручной миграции.
- Новых зависимостей и команд Tauri не требуется.
