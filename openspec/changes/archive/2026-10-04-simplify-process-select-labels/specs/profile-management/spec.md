# Spec Delta

## MODIFIED Requirements

### Requirement: Выбор процесса из процессов с окнами
Выбор процесса SHALL предлагать только процессы с видимым окном верхнего уровня, а при редактировании также сохранённый процесс, даже если он не запущен. В списке и выбранном значении SHALL показываться только имя исполняемого файла, без заголовков окон и дополнительных описаний, включая «не запущен». Профиль SHALL хранить имя исполняемого файла (например, `game.exe`). Пользователь SHALL иметь возможность обновить список.

#### Scenario: Игра запущена
- **WHEN** пользователь открывает выбор процесса при создании или редактировании профиля, пока игра запущена в окне
- **THEN** элемент игры показывает только имя exe без заголовка окна

#### Scenario: Фоновые процессы без окна
- **WHEN** в системе работают процессы без видимых окон
- **THEN** они не появляются в списке выбора, кроме сохранённого процесса редактируемого профиля

#### Scenario: Игру запустили после открытия списка
- **WHEN** пользователь запускает игру при открытом списке и нажимает «Обновить»
- **THEN** процесс игры появляется в списке только с именем exe

#### Scenario: Выбранный процесс
- **WHEN** пользователь выбирает процесс и закрывает список
- **THEN** поле выбора показывает только имя exe без заголовков окон и дополнительных описаний
- **AND** при сохранении профиля сохраняется имя exe

#### Scenario: Сохранённый процесс не запущен
- **WHEN** пользователь редактирует профиль, чей сохранённый процесс отсутствует среди запущенных процессов с окнами
- **THEN** сохранённый процесс остаётся выбранным и доступным в списке только под именем exe без подписи «не запущен»
