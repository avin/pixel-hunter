# Proposal

## Why

В выборе процесса заголовки окон перегружают список и выбранное значение. Пользователю нужны только названия процессов — имена исполняемых файлов.

## What Changes

- В списке процессов при создании и редактировании профиля показывать только имя exe.
- Убрать вторую строку с заголовками окон и подпись «не запущен» у сохранённого процесса.
- В закрытом селекте также показывать только имя выбранного exe.
- Сохранить обновление списка, фильтрацию процессов с видимыми окнами и возможность выбрать сохранённый процесс, который сейчас не запущен.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `profile-management`: выбор процесса показывает только имя исполняемого файла без заголовков окон и дополнительных описаний.

## Impact

Изменение затрагивает отображение элементов Select в `src/components/pages/ProfilesPage/ProfileDialog/ProfileDialog.tsx` и существующие поведенческие проверки в `ProfileDialog.test.tsx`. API, `WindowedProcess`, получение процессов в Rust и формат хранения профиля менять не требуется.
