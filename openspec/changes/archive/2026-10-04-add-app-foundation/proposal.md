# Proposal

## Why

Pixel Hunter — приложение для Windows 10/11, которое следит за цветом пикселей на экране игры и при совпадении условий выполняет действие (например, серию нажатий клавиш). Сейчас в репозитории только шаблон Tauri с демо-страницами. Нужен фундамент, на котором строятся захват пикселей, действия и движок отслеживания: права администратора, хранилище конфигурации, профили с привязкой к процессу игры и список отслеживаний.

Это первое из четырёх изменений, разбитых по слоям: `add-app-foundation` → `add-pixel-capture`, `add-key-sequence-action` → `add-tracking-engine`.

## What Changes

- Release-сборка требует прав администратора: манифест `requireAdministrator` плюс проверка прав при старте и перезапуск через `runas`, по образцу PoeLifer. Debug-сборка права не поднимает.
- Rust-часть владеет конфигурацией и хранит её в JSON-файле в каталоге данных приложения.
- Экран списка профилей: создание, открытие, удаление.
- Профиль: имя и процесс игры, выбранный из списка процессов, у которых есть видимое окно.
- Внутри профиля: список отслеживаний с созданием, переименованием и удалением, а также настройки времени отслеживания (задержка перед действием, пауза до возобновления опроса).
- Демо-страницы шаблона (Home, Settings, About, `greet`) удаляются. Приложение переименовывается из `hello-app` в `pixel-hunter`.
- Подключается тестовая инфраструктура фронтенда: Vitest и Testing Library.

## Capabilities

### New Capabilities

- `admin-elevation`: запуск приложения с правами администратора.
- `profile-management`: профили, привязанные к процессу игры, их создание, открытие и удаление, хранение между запусками.
- `tracker-management`: отслеживания внутри профиля, их создание, переименование, удаление и настройки времени.

### Modified Capabilities

Нет.

## Impact

- `src-tauri`: новые зависимости `windows` (Win32 API) и `uuid`; модули хранилища, профилей и списка процессов; `build.rs` с манифестом; `main.rs` с проверкой прав; переименование крейта и `productName`/`identifier`.
- `src`: новые страницы и маршруты, RTK Query endpoints для команд Tauri, удаление демо-страниц и боковой навигации шаблона.
- Новые UI-примитивы shadcn/ui (таблица, диалог, select/combobox, тосты).
- Разработка: проверка на играх, запущенных от администратора, требует терминала или IDE с правами администратора.
