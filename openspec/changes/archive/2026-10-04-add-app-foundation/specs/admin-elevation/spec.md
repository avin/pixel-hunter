# Spec Delta

## Purpose

Гарантирует, что приложение работает с правами администратора, иначе Windows блокирует эмуляцию ввода в игры, запущенные от администратора.

## ADDED Requirements

### Requirement: Release-сборка запрашивает права администратора при запуске
Release-сборка приложения SHALL при запуске работать с правами администратора. Если приложение запущено без них, оно SHALL само запросить повышение прав через UAC и перезапустить себя, а исходный процесс без прав SHALL завершиться, не показывая интерфейс.

#### Scenario: Запуск обычным пользователем
- **WHEN** пользователь запускает release-сборку без прав администратора
- **THEN** Windows показывает запрос UAC на повышение прав
- **AND** после подтверждения открывается окно приложения, работающего с правами администратора

#### Scenario: Запуск уже с правами администратора
- **WHEN** release-сборка запускается процессом, у которого уже есть права администратора
- **THEN** приложение открывается сразу, без повторного перезапуска

#### Scenario: Пользователь отклонил запрос UAC
- **WHEN** пользователь отклоняет запрос UAC
- **THEN** приложение завершается, не открывая окно

### Requirement: Debug-сборка не поднимает права
Debug-сборка SHALL запускаться с правами того процесса, который её запустил, и SHALL NOT перезапускать себя через UAC.

#### Scenario: Запуск в режиме разработки
- **WHEN** разработчик запускает приложение через `npm run tauri dev` из обычного терминала
- **THEN** приложение открывается без запроса UAC и остаётся подключённым к dev-серверу
