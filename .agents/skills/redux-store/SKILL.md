# Redux Toolkit store

Применяй каждое правило ниже к каждому затронутому слайсу, селектору, API и месту состояния.

## Структура

- `src/store/index.ts` содержит `configureStore` и типы `RootState` / `AppDispatch`.
- `src/store/hooks.ts` содержит типизированные `useAppDispatch` / `useAppSelector`; в компонентах используй только их.
- `src/store/api.ts` содержит RTK Query API; Tauri-команды вызывай через `tauriBaseQuery`.
- Один доменный слайс — один файл `<domain>Slice.ts` в `src/store/`.
- Экспортируй слайс именованной константой `<domain>Slice`. Ключ редьюсера совпадает с `name` слайса и уникален во всём store.

## Типы и хуки

- Выводи `RootState` через `ReturnType<typeof store.getState>`, а `AppDispatch` — через `typeof store.dispatch`.
- Тип состояния слайса оставляй локальным, если внешний потребитель явно не требует его.
- Создавай типизированные хуки через `.withTypes`.
- Простые селекторы пиши inline. Сложные или переиспользуемые селекторы экспортируй именованными функциями из файла слайса.

## Состояние

- Временное состояние одного компонента оставляй локальным.
- Поднимай состояние только до ближайшего реального общего владельца.
- Помещай в Redux доменное состояние, которое нужно независимым частям дерева, должно переживать смену экранов или участвует в общем сценарии.
- Серверные данные и вызовы Tauri-команд веди через RTK Query, а не через отдельные слайсы.
- Один источник истины: локальное состояние, Context или Redux.

## Слайсы и экшены

- Не используй `createAsyncThunk`: для асинхронной логики возвращай обычную thunk-функцию из экшен-криэйтора или RTK Query endpoint.
- Предпочитай имена сеттеров `set...` (`setSessionStatus`), а не событийные варианты вроде `...Received`.
- Называй селекторы `xxxSelector` (`sessionStatusSelector`), а не `selectXxx`.
- В reducers изменяй draft-state напрямую через Immer.
- Экшены экспортируй именованной деструктуризацией из `<domain>Slice.actions`.
- Называй экшен глаголом, описывающим событие (`acknowledge`, `resetDemo`); для записи значения в состояние используй `set...`.
